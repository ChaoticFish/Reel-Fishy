# Reel Fishy demo

Two stand-alone pages that show every player feature: `reel-fishy-demo.html` and `reel-fishy-demo-page2.html` (page two shows the player carrying over between pages). Open them in a browser; the player script is inlined, so they need no Joomla site.

YouTube, Vimeo and TikTok players load only after you press play.
